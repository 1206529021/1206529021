## Agent skills

### Issue tracker

Issues and specs live as local markdown files under `.scratch/<feature-slug>/` — no external tracker. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, all written as `triage:*` strings on the `Status:` line of an issue file. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root, created on demand. See `docs/agents/domain.md`.
